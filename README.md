# swccg-data
Data Collection for Star Wars CCG

## Public Files
### cardfacts.txt
This file contains all the card definitions and is used by the AI to answer questions about the game. It is generated by the generateCardFacts.js script.

### tournaments.json
This file contains all the tournament decklists from the PC website. It is generated by the scrapeDecklists.js script.

## players.json
This file contains info on every player who has played in a major tournament since 2019.

## decklists.json
This file contains info on every decklist from every major tournament since 2019.

## decklists.txt
This file is a text concatenation of every decklist from every major tournament since 2019.

## card-history.json
Every card title a decklist has matched, by side, with its card ID and image. When upstream renames a card (The Emperor (V) → The Emperor, Relentless) the old title resolves through its ID to the current card; when upstream removes one (No Bargain (V)), old decks keep the archived entry. Maintained by generateDecklistJson.js; don't delete it.


### Other Files
All other files are generated by scripts.


## Setup
### Card Facts
`node generateCardFacts.js`
This will download the card definition JSON files, card images, and generate the cardFacts.txt file.

### Download Decklists
`node scrapeDecklists.js`
This will download all tournament decklists from the PC website. Run `node scrapeTournaments.js` first to generate the tournaments.json file.

### Download Card Images
`node downloadCardImages.js`
This will download all images for all cards locally.

### Scrape Tournament Data
`node scrapeTournaments.js`
Scrapes the PC website for tournament data and generates the tournaments.json file. This is a pre-requisite for the scrapeDecklists.js script.


### Monthly refresh
`.github/workflows/refresh-data.yml` runs `bootstrap.sh` at 12:00 UTC on the 1st of every month (or on demand from the Actions tab) and commits `public/` when anything changed. It needs the `ANTIBOT_QUERY` repository secret (the same value as in `.env`). Scraped decklist pages are kept in the Actions cache, so only new decklists are fetched; with a cold cache the run re-scrapes everything (about 3 hours). The run fails rather than publishing a `decklists.json` with fewer decklists than before.

To run it locally: `sh bootstrap.sh`.
